Relacionamentos mapeados (JPA):
  • Competicao → Modalidade — @ManyToOne (muitas competições para 1 modalidade)
  • Equipe → Modalidade — @ManyToOne (optional=false)
  • Equipe → Clube — @ManyToOne
  • Atleta → Endereco — @Embedded (composição)
  • Clube → Endereco — objeto embutível (composição)
  • Atleta.sexo → Sexo — @Enumerated(STRING)
  • Competicao.status → StatusCompeticao — @Enumerated(STRING)

Observações: não há relacionamentos bidirecionais (sem @OneToMany com mappedBy); Equipe.id é do tipo Integer (demais PKs são Long); Atleta.nomeCompleto e Atleta.cpf são únicos.
