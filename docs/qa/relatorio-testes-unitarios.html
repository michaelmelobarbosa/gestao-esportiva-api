Estratégia e reprodução

Como os testes estão organizados e como executá-los.

Abordagem

  • Testes unitários puros de Service, sem contexto Spring e sem banco de dados.
  • Colaboradores isolados com @Mock (Mockito) e verificação de interações.
  • Padrão AAA (Arrange–Act–Assert) com nomes e @DisplayName descritivos.
  • Agrupamento por comportamento com @Nested (findAll, save, update...).
  • Tempo determinístico com Clock.fixed nos testes que dependem de idade/data.
  • Assertivas legíveis com AssertJ e builders de dados reutilizáveis.

Como executar

Só os testes de service (não exige Docker/MySQL):

./mvnw -Dtest='*ServiceTest' test

Executar um serviço específico:

./mvnw -Dtest=AtletaServiceTest test

Suíte completa (exige MySQL via docker compose up -d):

./mvnw test
